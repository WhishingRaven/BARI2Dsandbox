# 실험과 검증

## 1. 결정적 검증 항목

강화학습 전에 다음 동작을 결정적으로 검증한다.

1. 로봇의 이동과 조향
2. IR의 로봇 및 간극 경계 감지
3. 접촉과 등반
4. 앵커 생성, 해제와 파손
5. 접촉 그래프의 간선과 연결성
6. 제방 간 횡단 판정
7. 수동 구조의 양수 하중 용량
8. 병렬 보강 구조의 더 높은 용량
9. 보상 항의 부호와 성공 조건
10. 모든 행위자 절제 구조와 두 비평가의 출력 형상
11. 실제 롤아웃을 포함한 MAPPO 한 업데이트

현재 전체 시험은 26개이며 모두 bari2d Conda 환경에서 통과한다. 수동 구조에서 단일 지지 행은 7.5, 두 병렬 지지 행은 15.0의 용량을 갖는다.

    conda run -n bari2d pytest
    conda run -n bari2d python scripts/verify_scripted.py

## 2. 핵심 지표

에피소드마다 다음 값을 기록한다.

- 성공 여부
- 간극 폭, 방향, 불규칙성, 주파수와 위상
- 목표 하중과 최종 용량
- 용량 대 목표 비율
- 시공 시간
- 사용 로봇 수와 앵커 로봇 수
- 총 이동 에너지 프록시
- 앵커 파손 및 낙하 로봇 수
- 최대 연결 진행도
- 최종 접촉 그래프와 로봇 형상
- 행동 분포와 가지별 잠재 통계

## 3. 권장 실험 설계

각 정책 절제에 대해 최소 다음 축을 분리한다.

- 훈련 시드
- 평가 시드
- 커리큘럼 단계
- 목표 하중 구간
- 간극 폭 구간
- 센서 및 구동기 잡음
- MLP 또는 그래프 비평가

최종 보고에서는 평균뿐 아니라 분산, 실패 유형과 조건별 성공률을 함께 제시한다.

## 4. 일반화 평가

훈련에서 사용하지 않은 시드로 4단계 환경을 생성한다. 폭, 방향, 경계 불규칙성, 마찰, 질량, 앵커 강도와 잡음을 동시에 바꾼다.

일반화 성공은 다음을 모두 만족해야 한다.

- 제방 간 연결
- 목표 하중 이상의 종단 용량
- 허용 가능한 시공 시간
- 에너지와 로봇 사용량이 기준선보다 악화되지 않음

## 5. 결과 해석

현재 저장소는 학습 가능한 기준선과 검증된 실행 경로를 제공한다. 장시간 훈련 수렴이나 사전 학습 정책의 성능을 주장하지 않는다.

구조 평가기는 연구용 그래프 근사다. 실제 구조 안전성이나 로봇 하드웨어 전이를 주장하려면 고정밀 물리, 시스템 식별과 별도 실험 검증이 필요하다.

## 6. 재현 가능한 실행

기준 GRU:

    conda run -n bari2d python scripts/train.py \
      --config configs/baseline.yaml --updates 1000

전체 FiLM 정책과 그래프 비평가:

    conda run -n bari2d python scripts/train.py \
      --config configs/bio_film.yaml --updates 1000

단계 4 평가:

    conda run -n bari2d python scripts/evaluate.py \
      runs/baseline/checkpoint_001000.pt \
      --config configs/baseline.yaml --stage 4 --episodes 100
